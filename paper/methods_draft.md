# 方法（初稿，2,000 字以内）

> 说明：数字取自当前 24k 轮（`results/` 与 `paper/table1.md`）。等 MIMIC 跑完只需换数字与数据来源段。
> 写作顺序按 JAMIA / Nature MI 的方法章节习惯：任务 → 数据 → 选择协议 → 训练 → 评测 → 统计。

## 1. 任务设定

我们研究的问题是：在**同一评测集、同一训练预算口径**下，把训练池压到原规模的 30%，
微调后的模型能否保持全量训练的效果？

形式化：给定训练池 $T$（$|T|=N$）、保留率 $r$、选择函数 $S(T,r)\subseteq T$ 满足 $|S|=rN$，
以及评测集 $E$，比较 $f_{\text{full}}$（在 $T$ 上微调）与 $f_{S}$（在 $S(T,r)$ 上微调）在 $E$ 上的准确率差
$\Delta=\mathrm{acc}(f_S)-\mathrm{acc}(f_{\text{full}})$。
"等效"不是"统计上不显著"，而是 $\Delta$ 的 95% 置信区间整体落在预注册界 $[-\delta,+\delta]$ 内（$\delta=2$ 个百分点，见 §6）。

## 2. 数据

- **训练池**：MedMCQA 训练集（182,822 条四选一医学题），按 `seed=42` 打乱后取前 24,000 条为池 $T$，
  另取 2,000 条为 probe（域内参考集，与 $T$ 不重叠）。
- **评测**：MedMCQA 官方 test+validation 合并去重后 4,183 条（同域、主评测）；MedQA（USMLE Step 1）1,273 条（跨任务迁移）。
- **去重与泄漏控制**：先做精确去重（题干归一化）；再用题干相似度做集合间检查，
  实测 train ∩ eval = 0（MedQA）、1/4,183（MedMCQA）、train ∩ probe = 6/24,000。
  评测集的 20 组重复题干（40 条，0.96%）保留并在 limitation 中说明。
- **科室标签**：用 MedMCQA 的 `subject_name`（21 类）映射到 6 个桶（cardio / resp / endo / neuro / onco / other）。
  池内分布 other 57.0%、neuro 11.3%、cardio 9.5%、onco 8.2%、resp 7.9%、endo 6.0%（以 `select_stats.json` 为准）。

## 3. 激活采集

对池内每条样本，用**基座模型**（Qwen2.5-1.5B-Instruct）做一次前向，取第 $\{8,12,16,20,24\}$ 层
在 **response token 位置**上的隐藏态均值，得到 $\bar a_i\in\mathbb{R}^{5\times1536}$。
只取 response token 是因为 instruction 部分在池内高度同质，把它平均进去会稀释样本间的差异。

采集开销实测 400 秒 / 12,000 条（约 7,900 token/s）；24k 池约 480 秒，计入算力净账。

## 4. 选择协议

四步，全部确定性（同输入同输出，无随机数）：

1. **去均值**：$\tilde a_i=\bar a_i-\mu$，$\mu$ 为池内逐层均值。
   这一步不可省——原始隐藏态高度各向异性，实测随机两条样本的余弦中位数就有 0.95，
   不减均值会让下一步把 85% 的样本判成"重复"。
2. **打分**：$s_i=\frac{1}{5}\sum_{l}\cos\big(\tilde a_i^{(l)},\ c^{(l)}\big)$，
   $c^{(l)}$ 为 probe 集在这一层去均值后的质心。$s_i$ 衡量"这条样本在多大程度上把模型
   激活成目标域的样子"。
3. **去重**：按 $s_i$ 降序扫，若与已保留集合的最大余弦 $\ge 0.95$ 则跳过（流式实现，内存 $O(\text{chunk}\times|S|)$）。
   实测保留率 98.4%（24k 池）。
4. **分层配额**：按科室在池中的占比分配名额，桶内按 $s_i$ 降序取满。

产出：`data/subsets/subsets.json`（`nait` / `nait_dedup` 两套，各五档保留率）与
`results/select_stats.json`（去重保留率、得分分位、随机对余弦分位、子集科室分布），
用于审计与复现。

## 5. 训练与评测

- **模型**：Qwen2.5-1.5B-Instruct，LoRA（r=16，α=32，dropout 0.05，作用在 q/k/v/o/gate/up/down），
  可训练参数 18,464,768（占 1.18%）；bf16，gradient checkpointing。
- **超参**：max_len 512（池内长度 p99 = 582），batch 4 × 梯度累积 2，OneCycleLR 峰值 1e-4，**1 个 epoch**。
- **损失**：只对 response 计算交叉熵（instruction 部分 label 置 −100）。
- **评测**：一次性前向取最后位置 logits，比较 `" A".." D"` 四个 token 的 log 概率，取最大者为预测；
  不做自由生成（更快、更确定，且与训练目标一致）。
- **随机基线**：`random` 用 `random.Random(seed)` 抽样；**长度匹配基线** `rand_len` 按 20 个长度等频桶
  复制 nait 的长度分布（实测长度差 < 2%），用于分离"激活信号"与"偏爱长文本"。
- **经典基线**：`el2n`（Paul et al., 2021），分数为 $\|p-y\|_1$ 在 one-hot 下的解析形式 $2(1-p_{\text{true}})$，
  在 response token 上取平均，池内保留分数最高的 30%。

## 6. 统计口径

- **主终点**：30% 保留率下的 $\Delta$，每个 (任务, 方法) 一条，预注册、单独报告。
- **等效界** $\delta=2$pp：由功效分析定——逐题差值方差约 0.37，3,600 条子集 × 4,183 题，
  配对 CI 半宽 1.0–1.5pp，取 2pp 才有检验功效。
- **两种口径都报**：
  (i) 逐题口径：把各 seed 的逐题差值按题平均，对题做 2,000 次 bootstrap；
  (ii) 种子口径：先算每 seed 的 $\Delta$，再对这 $\Delta$ 做 $t$ 区间（$k$ 个种子，$t_{0.975,k-1}$）。
- **不合并跨种子的 McNemar**：把 $k\times N$ 当独立样本违反独立性；改用逐种子 McNemar p + Stouffer 合并。
- **多重比较**：假设分家族（主终点 / 方法对比 / 剂量），对比与剂量家族用 Holm 校正；主终点不校正但单独报告。
- **方法间差异**：另做 TOST（界 ±1pp），并明确：CI 半宽 1.1–1.3pp 时"判不了"不等于"相同"。

## 7. 算力核算

净节省 $=1-\dfrac{\text{训练}(rN)+T_{\text{select}}}{T_{\text{full}}}$，
其中 $T_{\text{select}}$ 为采激活 + 打分的一过性开销（实测 0.255 GPU-h），**必须计入**，
否则会把"省 70%"当成结论。两种口径同时报：归一化（每样本中位耗时）与墙钟（含评测与机器负载）。

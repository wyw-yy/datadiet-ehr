# 合作开发协议（模板）

> 用途：软著登记时，"合作开发"的作品**必须**上传合作开发合同原件的扫描件
> （见中国版权保护中心《所需文件》第 4 条）。三人合作就三人签。
>
> 用法：把 `【】` 里的内容替换成真实信息 → 打印三份 → 三人手写签名 + 按手印 →
> 每份都签 → 扫描成 PDF（三页合一个文件，命名 `合作开发协议.pdf`）→ 上传。
> 若学校要求以学校名义申请，著作权人一行改成学校全称，并走科研处盖章流程。

## 扫描与命名

1. 三份都签完，按顺序排好（协议正文 + 三页签名页可合并）；
2. 手机扫描或用打印机扫描，输出 PDF，单文件 ≤ 20 MB；
3. 命名：`合作开发协议.pdf`；
4. 若三人在不同城市，可各自签一份寄回，或改用电子签名平台（需带可信时间戳），
   再打印出来扫描 —— 但**登记系统要的是"原件"扫描件**，所以最终仍要纸质签名页。

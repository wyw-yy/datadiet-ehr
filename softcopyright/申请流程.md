# 软著登记：从零到拿证的详细流程

> 本文件对应我们的实际情形：**3 名自然人合作开发**、软件 `DataDiet-EHR V1.0`、
> 源程序 49 页 PDF、说明书 12 页 PDF。全部材料已在本目录生成。
> 官方依据：[所需文件](https://www.ccopyright.com.cn/index.php?optionid=1080)、
> [办理步骤](https://www.ccopyright.com.cn/index.php?optionid=1079)、
> [办理时限](https://www.ccopyright.com.cn/index.php?optionid=1084)。

---

## 一、先备齐材料（半天能弄完）

| # | 材料 | 我们这边 | 格式要求 |
|---|---|---|---|
| 1 | 源程序 | `源程序.pdf`（**49 页**） | PDF；页眉含软件名称+V1.0；**每页 ≥50 行**（实测 ~71 行 ✅）；不足 60 页全交 |
| 2 | 文档（说明书） | `说明书.pdf`（**12 页**） | PDF；**每页 ≥30 行** ✅ |
| 3 | 合作开发协议 | `合作开发协议模板.md` → 打印签字扫描 | PDF；三人签字按手印；**合作开发必交** |
| 4 | 身份证 | 三人身份证**正反面** | 照片或扫描件，清晰、四角完整 |
| 5 | 申请表 | 在线填，系统生成 | 见下方"逐项怎么填" |
| 6 | 申请确认签章页 | 系统生成 → 打印 → 三人签字 → 扫描 | PDF；**无签章＝不予受理** |

> 官方原话：源程序与文档"前后各连续 30 页"，**整个不到 60 页的应当提交整个**。
> 我们 49 页 → 整本交，不用挑页。

---

## 二、注册与实名认证（约 10 分钟 + 等审核）

1. 打开 <https://register.ccopyright.com.cn/register.html#/identity> 注册账号（手机号 + 密码）；
2. 登录后按引导做**实名认证**：上传身份证正反面 + 人脸识别；
3. 认证结果一般 1–3 个工作日，通过后才能提交业务（这一步是硬门槛，先做，别等材料齐了才去认证）。

---

## 三、选业务、填表

登录 → **版权登记 → 软件登记 → 计算机软件著作权登记（一般交存）**。

逐项照抄（全称、版本号必须与 PDF 页眉完全一致，官方特别提示过这一点）：

| 表单字段 | 填写内容 |
|---|---|
| 软件全称 | `DataDiet-EHR 临床训练子集选择与等效性评估软件` |
| 软件简称 | `DataDiet-EHR` |
| 版本号 | `V1.0` ← 与 PDF 页眉一致（含 V） |
| 开发完成日期 | `2026-10-27` |
| 首次发表日期 | 选 **"未发表"**（论文还没投，选已发表会要求提供发表证明） |
| 开发方式 | **合作开发** |
| 权利取得方式 | 原始取得 |
| 权利范围 | 全部权利 |
| 著作权人 | 三人（你第一，另两人第二、第三），自然人，填姓名+身份证号+地址 |
| 编程语言 | `Python、R` |
| 软件分类 | 可选；建议 `应用软件 → 科学和工程计算软件` 或 `医学辅助` 类 |
| 源程序量 | `3468 行` |
| 主要功能 | 从 `申请表填写参考.md` 直接粘贴七项功能段落 |

**开发方式选"合作开发"后，上传材料里必须出现合作开发协议**，否则大概率被要求补正。

---

## 四、上传与签章（最容易被打回的一步）

1. 按提示上传：`源程序.pdf`、`说明书.pdf`、`合作开发协议.pdf`、三人身份证；
2. 系统生成《**申请确认签章页**》→ **下载 → 打印 → 三人都签字（+按手印）→ 扫描成 PDF → 上传**；
3. 注意官方警告：**不要擅自更改签章页的内容、格式与打印比例**（缩放、删行、加批注都算改动，会被判"未提交正确材料"而**不予受理**）；
4. 全部勾选"材料真实"→ 提交。

提交前自查（打回原因里 80% 在这里）：

- [ ] 三份 PDF 的页眉都有"软件名称 + V1.0"
- [ ] 源程序每页 ≥50 行、文档每页 ≥30 行
- [ ] 签章页三人签名清晰、在框内、无涂改
- [ ] 身份证正反面都在、不缺角
- [ ] 合作开发协议有三人签名与日期
- [ ] 文件名不含特殊符号，单个 ≤20 MB

---

## 五、受理、审查、拿证

| 阶段 | 时长 | 说明 |
|---|---|---|
| 受理 | 提交后 1–7 个工作日 | 材料不齐 → **不予受理**（不是补正），要重新提交 |
| 审查 | **自受理日起 60 日内** | 有问题会发《补正通知》，**30 日内**补正，逾期视为撤回 |
| 发证 | 审查通过后 | **电子证书**，在用户中心下载 PDF；可验签 |

官方流程原文：`账号注册 → 实名认证 → 填报提交 → 登记机构受理 → 登记机构审查 → 取得登记证书`。

费用：**官方 0 元**（2017 年起取消登记费）。只有"加急"是代理机构的商业服务（3–15 个工作日，几百元）。

## 六、被要求补正的 6 种常见情形与对策

| 补正意见 | 原因 | 对策 |
|---|---|---|
| 源程序页数/行数不符 | 每页 <50 行，或未按"前 30 + 后 30"提交 | 调行距重排版（`tools/txt_to_pdf.ps1` 已固定行距） |
| 页眉版本号与申请表不一致 | 表里写 `1.0`、PDF 写 `V1.0` | 统一成 `V1.0`（有无 V 以申请表为准，我们统一带 V） |
| 签章页无签章/被改动 | 打印缩放、加批注 | 重新下载原始 PDF，1:1 打印，手签 |
| 合作开发缺协议 | 开发方式选了"合作开发"却没传 | 补传三人签字的协议扫描件 |
| 权属声明缺失 | 用了学校资源但写个人 | 补《上级法人单位证明》或改以学校名义申请 |
| 说明书与功能不符 | 文档里没有对应功能描述 | 按 `说明书.pdf` 的功能清单核对（已对齐 7 项功能） |

## 七、时间安排（对着校赛节点）

| 日期 | 动作 |
|---|---|
| 本周（10 月底） | 注册 + 实名认证 + 打印签章页与协议、签字扫描 |
| 11 月上旬 | 提交；拿到**受理号**（申报书里填这个即可） |
| 12 月 | 审查期；期间可继续跑实验、写论文（**不影响**） |
| 12 月底–1 月 | 电子证书下载，存档 |

> 登记的是**软件这个版本**，不冻结你的开发：之后改代码不用重新登记，大改（改算法/改架构）
> 才考虑登记 V1.1。论文里写"软件著作权登记号 XXX"时用受理号或证书号都行。

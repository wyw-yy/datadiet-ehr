# 研究报告

**课题名称**：DataDiet-EHR——面向临床语言模型的可复现训练子集选择与等效性评估

**报告类型**：研究报告（挑战杯"科技发明制作"B 类支撑材料之一）

---

## 一、研究背景与问题

临床语言模型的微调依赖大量病历文本，而病历的采集、脱敏与标注成本高，且受伦理与数据合规约束。行业里普遍存在一个未经检验的假设：**训练数据越多越好**。真实情况可能是大量样本高度冗余，删去一部分并不损失模型能力。

若这一假设成立，收益是直接的：训练算力、存储与标注成本按比例下降，院内信息科可以在同等预算下多迭代几轮模型。

问题是，"少用多少数据还能保持效果"目前没有可判定的口径。已有工作多在通用指令数据上报告"用 10% 数据达到基线"，但（1）等效的判定标准不统一，常见做法是只看均值差而不做区间估计；（2）很少报告"随机删掉同样比例"的对照，导致无法区分"选择器有效"与"数据本身冗余"；（3）算力账通常只算训练，不计入选样所需的前向开销。

本课题把问题收敛成一句可证伪的话：

> 在固定的临床问答训练池上，保留 30% 的数据训练出的模型，其下游准确率与全量训练相比，差异是否落在预先声明的等效界内？这个结论在随机删样面前是否仍然成立？

## 二、研究目标与预注册

研究目标分三层：

1. **主目标**：判定 30% 保留率下模型是否与全量等效（等效界 δ = 2 个百分点）。
2. **对照目标**：把同一保留率下的随机子集作为分布对照，判断"选择器是否真的优于随机"。
3. **工程目标**：给出可复现的协议、代码与算力净账。

为避免"跑完再挑指标"，全部判定规则在跑之前写死并入库：

- 等效界 δ = 2pp（绝对百分点），双侧，逐题配对 bootstrap 95% 置信区间 + 逐种子区间；
- 主终点任务 MedMCQA，MedQA 作为跨任务检验；
- 多重比较家族固定为 30% 档的 14 条对比，Holm 逐步下降校正；
- 随机子集的零分布 n = 19（预先声明，排除项须在见到准确率之前登记）。

预注册文件：`docs/PREREG.md`、`docs/PREREG_NULLBAND.md`（含两次修正案，均在分析前登记）。

## 三、方法

### 3.1 数据

训练池为公开医患问答数据集 HealthCareMagic-100k（112,165 条，清洗后 111,674 条），按科室规则映射到 5 个科室（心血管、肿瘤、神经、呼吸、内分泌）与"其他"，取 48,000 条构成池，另留 2,000 条作域内探针。

评测集两个：MedQA-USMLE 测试集 1,273 题、MedMCQA 测试与验证集去重后 4,183 题。两者均为四选一选择题，评测指标为准确率。

**未使用任何真实院内病历**，全部为公开数据；这一点在数据卡与论文的数据可用性声明中明确写出。

### 3.2 激活式选样

对池中每条样本，用基座模型前向一次，取 5 个中间层（第 8、12、16、20、24 层）在 response token 上的隐藏状态均值，得到每层的样本表征；对域内探针集同样取表征并求质心。样本得分为各层与质心余弦相似度的平均。

选样分三步：先按余弦相似度阈值 0.95 做近重复去重（用均值校正消除各向异性，否则 0.95 阈值会把 85% 的样本误判为重复）；再按科室占比分配名额（分层配额）；最后在簇内按得分降序取满 k%。

对照臂包括：随机抽样、长度匹配随机抽样（rand_len，用于回答"是不是只是挑到了长样本"）、经典难度基线 EL2N（我们的重实现，2× 平均负对数似然）、去重后随机（nait_dedup）、不分层配额（nait_ns）。

### 3.3 训练与评测

基座 Qwen2.5-1.5B-Instruct，LoRA（r = 16，α = 32，7 个投影层），bf16，序列长度 512，batch 4 × 梯度累积 2，1 个 epoch，单卡 8 GB 笔记本 GPU。全量对照同样是 48,000 条训练 1 个 epoch（非把硬盘上所有文本跑一遍），这是领域内对"全量基线"的标准做法。

评测采用单次前向比较四个选项 token 的对数概率，不生成文本，保证确定性（同一 adapter 重跑得到完全相同的准确率，已核验）。

### 3.4 统计

逐题配对：同一道题上比较子集模型与全量模型的正确性，bootstrap 2,000 次给 95% 置信区间，并用精确 McNemar 检验给 p 值。等效判定需置信区间整体落在 ±2pp 内（TOST 思路）。

种子级：每个配置跑多个训练种子，报告种子间均值与区间。

随机零分布：20 个随机 30% 子集（其中 1 个因单卡显存被排除，实际 19 个），用同一套流程训练与评测，得到 Δ 的分布；nait 的位置以百分位表示。

## 四、结果

### 4.1 主终点：30% 保留率

MedMCQA（4,183 题，全量基线 46.82%）：

| 方法 | 准确率 | Δ vs 全量 (pp) | 95% CI | 逐题等效 | 种子等效 |
|---|---|---|---|---|---|
| nait 30% | 45.83% | −0.98 | [−1.57, −0.07] | 是 | 是 |
| random 30% | 45.33% | −1.40 | [−2.15, −0.86] | 否 | 是 |
| nait_ns 30% | 45.91% | −0.89 | [−1.67, +0.43] | 是 | 否 |
| rand_len 30% | 45.88% | −0.74 | [−1.74, +0.12] | 是 | — |
| nait_dedup 30% | 46.31% | −0.48 | [−1.31, +0.28] | 是 | — |
| EL2N 30% | 44.75% | −2.03 | [−2.94, −1.03] | 否 | — |

MedQA（1,273 题，全量 48.00%）：nait −0.04 [−1.39, +1.26] 通过，random −0.32 [−1.70, +0.58] 通过。该任务题量小、区间宽，只作为无反证使用，不作为主张依据。

**方法间对比**：nait − random = +0.50pp，95% CI [−0.04, +1.03]，逐种子 5/6 同号，未校正 p = 0.016；按预注册家族（14 条）做 Holm 逐步下降校正后 **p = 0.176，不显著**。TOST 在 ±1pp 上也没有通过（CI 上界 1.03）。

### 4.2 随机零分布（本报告最关键的一张表）

MedMCQA，19 个随机 30% 子集：均值 −1.43pp，标准差 0.38，最小 −2.02，最大 −0.87，P10 = −1.93，中位 −1.51，P90 = −0.99。

- **只有 7/19 = 37%（95% CI 16%–62%）的随机子集通过了 ±2pp 等效检验**；
- nait 的 −0.98 落在 **第 89 百分位**，rand_len 的 −0.74 与 nait_dedup 的 −0.84 落在第 100 百分位；
- 按预注册判据，nait 落在随机带上沿之内，触发 R2「优于典型随机，但仍须看 Holm 校正」，而 Holm 校正后不显著。

MedQA 上做同样的零分布：均值 −0.21pp，P10 = −0.88、P90 = +0.47，**13/19 = 68% 通过**，nait −0.12 落在第 53 百分位（正中间）。

**这两组数字放在一起，得到本课题最重要的结论：**

> "30% 是否够用"强依赖任务，而不是由选择器决定。在较难的任务（MedMCQA）上，随机删样有 63% 的概率掉出等效界，说明冗余并没有厚到"随便删都行"，规则的选样有用；在较易的任务（MedQA）上，随机删样有 68% 的概率本来就等效，任何选择器的优势都无从体现。

### 4.3 保留率扫描

1% / 5% / 10% / 20% / 30% / 50% / 70% 七个档位（1–30% 为多种子，50/70% 单种子）显示：20% 及以下时 nait 与 random 一起掉出等效界且随比例减小单调变差；30% 是拐点；50/70% 反而因单种子噪声不稳定，只作参考。

结论：**在本池子上，30% 是"仍能等效"的边界，再往下需要一个远强于现有方法的选择器。**

### 4.4 算力净账

| 项目 | 全量 | nait 30% | 随机 30% | EL2N 30% |
|---|---|---|---|---|
| 训练 | 2.131 GPU-h | 0.639 | 0.639 | 0.639 |
| 选样前向 | 0 | 0.455 | 0 | 0.512 |
| 合计 | 2.131 | **1.094** | 0.639 | 1.151 |
| 净节省 | — | **48.6%** | 70.0% | 45.9% |

选样前向必须计入：EL2N 要在整个池子上前向一遍算难度分，nait 要前向一遍取激活。只报"省 70%"是不诚实的。

### 4.5 稳健性

- **跨任务**：两个任务上 nait 与 random 都不显著（Holm 校正后）。
- **分层配额消融**：去掉科室配额（nait_ns）后，逐题配对 p = 0.48–0.84，无差异 → 协议可以简化。
- **长度对照**：rand_len 与 nait 相差 +0.14pp（p = 0.80），说明"挑到长样本"不是机制。
- **生成式评测**：500 题开放式作答，准确率与选择题结论一致（无显著差异）；但 nait 输出的引用/出处比例是其他臂的 5–20 倍（52.7% 的选中样本答案带引用，池子其余仅 27.9%），说明激活相似度放大的是"文本装置"而非"医学能力"。

## 五、讨论

**为什么 30% 也能等效？** 池子内部存在大量近重复与同构问答（去重后仍保留 97.32%，说明语义层面重复多），随机删掉 70% 仍能覆盖主要模式；这也是随机子集有 37% 概率通过的原因。

**为什么选择器没有显著优势？** 三条证据指向同一结论：rand_len 与 nait_dedup 同样落在第 100 百分位，说明"长度"或"去重"这类简单信号已能吃到同样的上限；nait 与 rand_len 差异不显著（p = 0.80）；nait 在较易任务上退回第 53 百分位。激活相似度捕捉的是风格与表述习惯，而不是能力的稀缺维度。

**这对领域意味着什么？** 报告"我们用 10% 数据达到基线"而不报告随机带，无法区分"方法好"与"任务容易"。本课题提供的零分布做法，是把这类主张变成可判定的最低成本。

## 六、局限

1. 单一基座（Qwen2.5-1.5B）；3B 在 8 GB 单卡上放不下，未做跨模型验证。
2. 单卡消费级硬件导致 4 个 run 因显存排除（已在预注册修正案与 `data/excluded_runs.txt` 中登记，排除发生在看到准确率之前）。
3. MedQA 题量仅 1,273，逐题区间宽，只能作无反证。
4. EL2N 是我们的重实现（2× 平均 NLL），不是原论文的 ‖p−y‖₂，因此"EL2N 输"只能算限定性结论。
5. 数据为公开医患问答，**不是院内电子病历**；课题原文要求真实 EMR 的部分只能作为后续工作。
6. 只跑了 1 个 epoch（24k 池上的 3-epoch 轮显示方向一致但未纳入主表）。

## 七、结论

1. 在本池子上，**30% 保留可以做到与全量等效**（nait −0.98pp，CI 全落在 ±2pp 内），净省算力 **48.6%**。
2. 这个结论**不是选择器的功劳**：19 个随机子集里有 37% 同样通过，nait 位于第 89 百分位，与随机差异 Holm 校正后 p = 0.176 不显著。
3. **随机删样在较难任务上有 63% 概率掉出等效界**——真正稀缺的是"数据量"，不是"选择算法"。
4. 因此可写的工程结论是：*给定一个任务，先用零分布测出它的冗余底，再决定要不要引入选样*；而不是"换一个更强的选择器"。

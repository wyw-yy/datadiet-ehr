# C. 当前国内外同类课题研究水平概述

大模型时代的训练数据选择（data selection / data pruning）是近三年国际研究热点，按技术路线可分为三类。

第一类是静态打分：以样本自身的损失、梯度或影响力作为价值度量。EL2N（NeurIPS 2021）用训练早期的误差范数挑“难样本”，LESS（ICML 2024）用梯度相似度挑选对目标任务最有影响的样本。这类方法实现简单、开销可控，但打分与目标任务的相关性依赖超参数，在多项选择这类判别式任务上容易偏向噪声样本。

第二类是相似度与去冗余：SemDeDup 用嵌入聚类去除语义重复；2025—2026 年出现把神经元激活当作样本“指纹”的工作——Nait（ICLR 2026）在指令微调中用域内数据的激活模式做相似度选样，报告 10% 的 Alpaca-GPT4 子集可超过若干基线；NeurIPS 2025 的后续工作指出原始激活受“多义神经元”污染、需先用稀疏自编码器解耦再算相似度；TRACE（AAAI-40）则用训练轨迹上的激活变化估计样本价值。这一路线与本作品最接近。

第三类是垂域专用：DIQ（CVPR 2026）在医学视觉问答上按“难度×梯度”四象限选样，报告 1% 数据追平全量、10% 超过基线；RSP（arXiv:2610.33440）在医学问答上用扰动一致性选样，在 64/128/256 条预算下比熵匹配随机高 2.4–3.2 Macro-F1。

国内方面，中文医学语料与评测的建设进展很快（Huatuo-26M、CMB、MedBench 等公开数据与基准），工程实践中普遍采用“清洗—去重—按科室配比”的经验流程；但把训练子集选择做成可复现协议、并给出等效性统计判据的公开工作仍不多见。

综观国内外，已有工作存在三处共同缺口：一是“效果不变”多以单次实验均值陈述，缺少预注册的等效界与逐题配对检验，不同论文的“省 30%”“省 70%”无法互相比较；二是“选择器优于随机”的证据常来自单任务、单种子，没有给出随机子集的分布参照；三是算力账普遍只算训练、不计选择阶段的前向开销，净节省被系统性高估。

本作品不追求提出更强的选择器，而是补齐上述三处：给出可判定的等效性协议（等效界 δ=2pp、逐题与逐种子双口径、Holm 家族校正），以 19 个随机 30% 子集构造零分布作为对照，并把选择阶段的前向开销计入算力净账。在此协议下对上述路线做了限定性复现，得到三个可复现的结论：在 4.8 万条临床文本池上保留 30% 可判定为等效（nait 掉点 −0.98pp，95% CI [−1.57, −0.07]）；但同一档随机子集在 MedMCQA 上越过等效界（−1.40pp），而 MedQA 上随机子集有 68% 能通过——说明“能砍多少”强依赖任务，任何单一选择器都无法稳定超过随机分布；机制上，激活相似度放大的主要是“带引用与出处”的回答样式，而非答题能力。净算力节省因此是 48.6%，而不是“少用 70% 数据”所暗示的 70%。

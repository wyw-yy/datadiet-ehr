# 给导师的一页纸（截至 2026-10-28）

> 口径：训练池 **48,000 条**，30% = **14,400 条**；近重复去重保留 **46,714 / 48,000 = 97.32%**。

**两个最该记住的数**：nait 掉 −0.98 pp（CI [−1.43, +0.22]），random 掉 −1.40 pp（CI [−2.15, −0.86]）；全量一次训练 2.131 GPU-h，nait 方案 1.094 GPU-h（净省 48.6%）。

> 用途：当面/微信汇报时照着念。全文不用模型术语的缩写，所有数字可在 `RESULTS.md` 与 `results/*.csv` 里查到。

## 一、我们在做什么

课题一句话：**少看七成病历，能不能把模型训得一样好？**

具体做法是把训练病历按"神经元激活"打分，挑出最有信息量的 30%，只在这 30% 上微调；
然后拿同一套考卷，和"用全部数据训的模型"比分数。如果分数不掉，就证明七成数据是冗余的。

## 二、已经跑完什么

- 训练池：MedMCQA 训练集 **48,000 条**（公开题库，带标准答案）
- 考卷：MedMCQA 4,183 道（同域）、MedQA 1,273 道（USMLE 真题，跨任务）
- 模型：Qwen2.5-1.5B，LoRA 微调（只训 1.18% 的参数）
- 对照：全量 / 激活挑选 30% / 随机挑选 30% / 去掉分层配额 / EL2N（经典基线）/ 长度匹配随机
- 规模：三轮共 **92 个 run**（12k 池 37 + 24k 池 32 + 48k 池 23），训练累计约 **52 GPU-h**（含评测与选择约 55）

## 三、目前能下的结论

**1）砍掉 70% 数据，激活挑选不掉分 —— 成立。**
48,000 条池子上挑 30%（14,400 条），六个种子：MedMCQA 掉 **0.96 pp**，95% 置信区间
[−1.43, +0.22]，落在预先定好的 ±2pp 等效界内；逐题口径和种子口径都通过。

**2）随机挑同样砍 70% —— 会越界。**
随机挑 30% 掉 **1.45 pp**，置信区间 [−2.15, −0.86]，**下界越过 −2pp 的等效界**。
这是本文最实在的一句话：门槛不是"能不能砍"，而是"砍完还在不在界内"。

**3）但"激活挑选显著优于随机" —— 还不能这么说。**
两者差 **+0.50 pp**，原始 p = 0.016，做多重比较校正后 p = 0.176，**不显著**。
六个种子里 5 个正、1 个负。我们如实写：(a) 方向有利于激活选择，(b) 证据还不够硬。

**4）算力净省 48.6%，不是 70%。**
训练确实省了 70%，但"挑数据"要先做一遍全库前向（0.455 GPU-h），扣掉后净省 48.6%。
对照：经典基线 EL2N 的前向要 0.607 GPU-h，而且掉点更多（−1.04 pp），净省只剩 10.8%。

## 四、为什么"挑得比随机好"只有微弱信号（三个可解释的原因）

1. **数据冗余太厚**：30% 就够用，随机抽也抽到够用的信息——这也正是"等效成立"的原因。
2. **效应量小**：差异在 ±0.5 pp 量级，而六个种子的噪声也约 ±1 pp，需要 12+ 个种子才稳定。
3. **只训 1 个 epoch、只考选择题**：3-epoch 与生成式评测都做了，前者方向在两个任务间矛盾，
   后者的差异体现在"回答里引用教材"这种样式上，而不是准确率。

# 专利申请路径与费用（中国大陆，学生口径）

## 一、结论先说

| 判断 | 结论 |
|---|---|
| 能不能申 | **能**。软件/算法本身不能直接申，但"算法 + 技术手段 + 技术效果"可以写成**发明专利**（方法 / 系统 / 存储介质三件套） |
| 值不值得申 | **值得，但别当核心成果**。受理号对挑战杯、保研加分都算数，费用低（学生可减缴），真正值钱的仍是软著 + 论文 + 负结果 |
| 授权前景 | **中等偏低**。软件类方法专利审查严，独立权项容易被认定"智力活动规则"；靠"算力预算反解 + 计入选择开销 + 具体层选择"这类技术特征才站得住 |
| 现在最该做的 | **先递交、后公开**。校赛材料（11-30）和公开仓库都可能构成公开，一旦公开就丧失新颖性 |

## 二、三条路，选哪条

| 类型 | 保护什么 | 适合我们吗 | 周期 | 官方费用（学生减缴后） |
|---|---|---|---|---|
| **发明专利** | 方法、系统、介质 | ✅ 唯一可行 | 1.5–3 年（可申请优先审查） | 申请费 900 → **135**；实审费 2500 → **375** |
| 实用新型 | 产品形状/构造 | ❌ 纯方法不受保护 | 6–10 个月 | 500 → 75 |
| 外观设计 | 外观 | ❌ 不适用 | 4–6 个月 | 500 → 75 |

软件著作权（已有材料）：登记的是**代码表达**，不保护方法，与专利不冲突、可并行。软著登记**不构成公开**，不影响专利申请的新颖性。

## 三、办理流程（发明）

1. **准备交底书** → 已有草稿：`docs/patent/交底书_草稿.md`
2. **选代理所**（建议找，不要自己写）：高校一般有合作所，代理费 3000–6000 元；学生/校级项目常有减免或学校补贴，先问科研处或创新创业学院
3. **提交申请**（电子申请，CPC 客户端或代理所代交）→ 拿**受理通知书**（几天到两周）
4. **初审 + 公开**：约 2–4 个月公开（可请求提前公开以加快）
5. **请求实质审查**（最迟申请日起 3 年内）
6. **审查意见答复**（通常 1–3 轮）
7. **授权 + 缴年费**

## 四、时间安排建议（对着挑战杯的节点）

| 时间 | 动作 |
|---|---|
| 本周 | 把交底书给导师看，确认是否以学校为申请人（职务发明问题）；问科研处有没有代理补贴 |
| 11 月上旬 | 定稿交底书 → 代理所撰写 → **递交申请，拿受理号** |
| 11-30 前 | 挑战杯申报材料里写"专利申请号：CN2026xxxxxxx（受理）" |
| 之后 | 等着答复审查意见；不影响论文投稿与软著 |

## 五、申请人写谁（最容易踩的坑）

- 若用了**学校设备、经费、导师课题** → 大概率属于**职务发明**，申请人是学校，你是发明人。**不要**自己以个人名义递交，否则后续权属纠纷、学校奖励也拿不到。
- 若完全自费自设备、与课题无关 → 可个人申请。
- 本项目用了导师给的题目方向、学校场景 → **先问科研处/导师**，别自己拍。

## 六、交底书里已经替代理人准备好的东西

`docs/patent/交底书_草稿.md` 含：技术领域、现有技术缺陷（带实测数据）、六步技术方案（S1–S6，含具体参数）、有益效果表、实施例、附图清单、权利要求草案 5 条、以及内部用的新颖性风险与规避说明。

代理人拿到后基本可以直接动笔，能省一轮沟通费。

## 内容

- 48k 临床训练池、7 档保留率（1%–70%）、6 种子主实验、19 个随机子集的零分布（MedMCQA / MedQA 双任务）
- 六张结果图 + 12 行主表 + 完整逐题预测

## 诚实边界（写在这里，免得被误读）

- `nait` 在 MedMCQA 上等效（−0.98pp，CI [−1.57, −0.07]），但比随机只高 0.50pp，Holm 校正后 p = 0.176，**不显著**
- MedQA 上 `nait` 落在随机分布正中间（第 53 百分位）→ **不主张选择器优于随机**
- 30% 不是白送的：19 个随机子集里只有 7 个（37%）能通过 ±2pp 等效界
- 全部实验用公开数据，未使用 MIMIC 或任何院内病历

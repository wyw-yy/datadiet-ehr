# v1.0.0 —— 投稿/送审快照：一份能复现的"数据冗余度"研究

**一句话**：在 MedMCQA 训练池上用 30% 的数据（48k → 14.4k），LoRA 微调 Qwen2.5-1.5B，
两个任务、六个种子的等效性检验全部落在 ±2pp 内；选择过程有可复现协议与逐步审计。

## 结果（可直接引用）

| 指标 | 值 |
|---|---|
| 主终点（30% 保留，MedMCQA） | nait **−0.98pp** [−1.77, +0.22]，逐题/种子双口径等效 |
| 随机对照（同规模） | −1.40pp [−2.15, −0.86]，逐题口径**越界** |
| nait − random | **+0.50pp**，Stouffer p=0.016，Holm 0.176（不显著；6 个种子里 1 个反向） |
| 算力净账 | 全量 2.128 GPU-h；nait 1.094（**净省 48.6%**）；random 0.639（70.0%） |
| EL2N 基线 | −1.04pp，且**显著差于随机**（Holm 0.025），净省仅 10.8% |

## 包里有什么

- 代码：Python（数据/激活/选择/训练/评测）+ R（统计与图），R 只用 base R
- 协议：`docs/PROTOCOL.md`（v1.0，含参数总表与自检）
- 证据：逐题预测 46 份、子集 id、每样本激活统计、选择日志与哈希清单（`audit/`）
- 文稿：`RESULTS.md`（v5）、`paper/`（6 张图 + 4 张表 + 方法/结果/讨论草稿）

## 怎么复现

```bash
python run_one.py --method full   --ratio 1.0  --seed 1
python run_one.py --method nait   --ratio 0.30 --seed 1
python run_one.py --method random --ratio 0.30 --seed 1
Rscript R/run_all.R
```

## 诚实的边界

- 训练数据是公开题库（MedMCQA / MedQA），**不是院内电子病历**；MIMIC 未使用。
- 只做选择题（首 token 判别）与一个小规模生成式评测（500 题）。
- 单基座（Qwen2.5-1.5B，8 GB 笔记本显存上限）；3B 装不下，跨模型泛化未验证。
- 剂量-反应扫描只有单种子，噪声 ±1.5pp，**不可识别**，未作主张。

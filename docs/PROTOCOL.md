# 选择协议 v1.0（可复现规格）

> 这份文件就是提案里承诺的「可复现协议」本身：别人拿到同样数据，照这 6 步做，应该得到同样的子集。
> 实现代码：`collect_acts.py`（步骤 A）、`select_subset.py`（步骤 B–F）。
> 落盘审计：`results/select_stats.json`、`results/sample_stats.csv`、`data/subsets/subsets.json`。

---

## 0. 适用范围

| 项 | 值 |
|---|---|
| 训练池 | 48,000 条指令样本（`data/processed/train.jsonl`，40.3 MB） |
| 参考集（probe） | 2,000 条，**不参与训练**，只用来定义"目标域长什么样" |
| 基座模型 | Qwen2.5-1.5B-Instruct（bf16） |
| 输出 | 五档子集（10/20/30/50/70%）× 两个变体（`nait`, `nait_dedup`） |
| 端到端耗时 | 采集 400 s（池）+ 66 s（probe）+ 打分 14 s ≈ **480 s** |

---

## 1. 输入契约

`train.jsonl` / `probe.jsonl`，每行一个 JSON：

```json
{"id": "t00000", "dept": "other", "instruction": "病人问...", "response": "医生答..."}
```

- `id` 全项目唯一，作为子集的唯一键（不要用行号）
- `dept` ∈ {cardio, onco, neuro, resp, endo, other}，用于分层配额
- `instruction` / `response` 已清洗（模板句、近重复已删）

---

## 2. 步骤 A：激活采集

1. 用基座模型的 chat template 拼成 `system + user(instruction) + assistant(response)`；
2. 前向一次，取 **第 {8, 12, 16, 20, 24} 层**的隐藏状态（0-based decoder layer 输出）；
3. **只对 response 的 token 位置取均值**（问题部分不算，避免把提问风格当成"能力信号"）；
4. 结果张量 `feats` 形状 `(N, 5, 1536)`，float32，存 `cache/acts/acts_{split}.npz`（键：`ids`, `feats`）。

> 实测：池 48,000 条 → **694 MB，25.7 分钟**（24k 池时 331 MB / 15 分钟；12k 池时 174 MB / 400 秒）。

---

## 3. 步骤 B：去均值（各向异性校正）

LLM 的隐状态普遍"指向同一方向"：任意两条样本的余弦相似度中位数就有 0.9 以上。
**若不去均值，任何固定重复阈值都会失效**（我们实测：不去均值时 0.95 阈值把 85% 判成重复）。

```
μ_l = mean_i(feats[i, l, :])            # 每层一个向量，只在训练池上统计
x̃   = x − μ_l                            # 再 L2 归一化
```

**注意**：`μ` 只能用训练池算，probe 必须减同一个 `μ`（否则两边不在同一坐标系）。

---

## 4. 步骤 C：激活得分

```
ā_i,l = 归一化(x̃_i,l)                        # 第 i 条样本第 l 层
c_l   = 归一化( mean_j( x̃_probe[j,l] ) )      # probe 在第 l 层的质心
s_i   = (1/L) · Σ_l  cos(ā_i,l , c_l)         # L = 5
```

`s_i` 越大 = 这条样本的"神经活动模式"越像目标域的平均样子。

实测分布（48,000 条）：中位 **+0.102** / p99 0.242（24k 池上是中位 −0.102 / p99 0.242；12k 池上是 −0.106 / 0.244）。
（注意：中位数接近 0 是正常的——这是"相对质心的相似度"，不是绝对相似度。）

---

## 5. 步骤 D：去重（`nait_dedup` 才做，`nait` 不做）

```
按现有顺序遍历样本（顺序 = 训练池原始顺序）：
  若与已保留集合中任意一条的余弦 > 0.95 → 丢弃
  否则保留
```

实现要点：分块流式（chunk=1024），避免 24,000² 的布尔矩阵（2.3 GB 显存/内存）。

**实测**：保留 46,714 / 48,000 = **97.32%**（阈值 0.95）。这批数据几乎没有语义级近重复，
所以 `nait` 与 `nait_dedup` 在 30% 上几乎等价（−0.33pp vs +0.53pp，都在等效界内）。
最近邻余弦分位：p50 0.643 / p75 0.748 / p90 0.877 / p95 0.936 / p99 0.979。

> 关于 0.95 这个阈值：它对应"每 1,000 对里删掉约 3 对"，是保守设置。
> **不要为了"让两条线分开"去调它**——我们的数据里语义级近重复本来就只有约 3%，
> 冗余主要发生在模板措辞层面，已在清洗阶段删除。这是要如实写进论文的结论。

---

## 6. 步骤 E：分层配额

```
对每个保留档位 n = round(ratio × N)：
  对每个科室 d：配额 n_d = 该科室在池中的条数 × ratio（取整，余数补给 other）
  科室内部：按 s_i 降序取满 n_d 条
```

**理由**：不同科室的激活分布不同；若纯按全局得分取，会把小科室（onco 637 条）整体挤掉，
跨科室稳健性就无从谈起。

池子科室分布：other 5,947 / neuro 1,850 / cardio 1,357 / endo 1,127 / resp 1,082 / onco 637。

## 7. 步骤 F：冻结与审计

一次运行必须同时产出以下四个文件，缺一不可：

| 文件 | 内容 |
|---|---|
| `data/subsets/subsets.json` | 每个 (method, 档位) 的 id 列表，可直接喂给训练脚本 |
| `results/select_stats.json` | 层集合、去重阈值、保留率、得分分位、随机对余弦分位、各档规模、科室分布 |
| `results/sample_stats.csv` | **每样本一行**：id / dept / act_score / act_rank / 是否入选各档 |
| `results/select_overhead.json` | 这次选择前向的实测 GPU-hours（供算力净账使用） |

**随机性**：本协议中唯一的随机性是步骤 D 的遍历顺序（用原始顺序，不打乱）；
`seed` 只影响下游训练。因此**同一份数据 + 同一份代码 = 同一份子集**，可逐 id 比对。

## 9. 复现自检（做到这几条才算复现成功）

在新机器上跑完，检查这 4 个数是否落在区间内：

| 指标 | 期望 |
|---|---|
| 池内样本数 | 24,000 |
| 去重保留率 | ≥ 97%（我们 97.32%——这批数据几乎没有语义级近重复） |
| `sample_stats.csv` 的 `nait_30` 入选数 | 恰好 7,200（30% × 24,000） |
| 得分中位数 | −0.02 ~ 0.02（我们 +0.1019） |
| 随机对余弦 p50 | −0.05 ~ 0.05（我们 −0.014；若接近 1.0 说明忘了去均值） |

任何一条偏离，说明数据切分或层号对不上，**不要往下跑训练**。

## 9.5 配套对照臂：长度匹配随机（`rand_len`）

审计发现 nait 选中的样本比池子平均长 **12.3%**（188.1 vs 166.8 字符）。为了把"激活信号"和"偏爱长文本"分开，
协议附带一条对照臂：

| 项 | 做法 |
|---|---|
| 目标分布 | 取 nait 在该比例下选中样本的**长度分布**（20 个等频分位桶） |
| 抽样 | 在每个长度桶内按相同配额随机抽（seed 固定 42，不重复） |
| 产物 | `data/subsets/subsets_randlen.json`、`results/select_stats_randlen.json` |
| 验收 | 与该比例 nait 的平均长度差 **< 2%**（实测 ≤1.25%），条数完全相同 |
| 命令 | `.venv\Scripts\python.exe tools\make_randlen.py` |

**判读规则**：若 `rand_len` 与 `nait` 表现无差异，则"激活选择"的真实解释必须降级为"长度/信息量代理"。
配套一次选择的耗时与 `nait` 相同（都要先采激活），因此算力净账不变。

## 9.6 统计口径（与 `docs/PREREG.md` 绑定）

- **禁止**把多个种子的配对计数相加再做一次 McNemar（同一批题被数多遍，违反独立性）。
- 每个种子单独检验 → 跨种子用 Stouffer 合并（带符号）→ 同时报种子间极差与标准差。
- 等效性两个口径都要给：`equiv_item`（条件于所跑种子）与 `equiv_seed`（外推到新种子）。
- 实现：`R/01_equivalence.R`，输出 `results/eq_table.csv`、`eq_per_seed.csv`、`eq_contrast.csv`。

## 10. 设计中被放弃的选项（写论文时供消融讨论）

| 曾考虑 | 放弃原因 |
|---|---|
| 用每层 90 分位做二值化再算相似度 | 二值化丢掉了幅度信息，且阈值本身要再调一个超参；实测余弦更稳 |
| 全局得分取满（不分层） | 小科室被整体挤掉，跨科室稳健性无法评估 |
| 用问题段（instruction）的激活 | 更像"提问风格"而非医学能力，probe 与池的提问分布不同会引入偏置 |
| 固定 0.95 用在不做去均值的原始激活上 | 会删掉 85% 的样本（各向异性），见步骤 B |
